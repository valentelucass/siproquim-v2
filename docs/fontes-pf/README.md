# Biblioteca oficial do módulo Mapas

Cópias consultadas em 22/11/2026. Para o conversor de transporte, comece pelo manual v1.1, pelo comunicado de transporte e pelos roteiros 11, 12 e 17 a 21. Os 21 roteiros cobrem o restante do módulo e retratam as telas de 2019. Para o envio atual de uma transportadora, aplique as mudanças posteriores da PF. A portaria em PDF é a publicação original. O texto consolidado e os comunicados estão no [índice de fontes](../fontes-oficiais.md).
